# PosEGNN

!!! info "Optional dependency"

    `PosEGNNCalculator` has no installable package on any public index. Clone the repository and add its module directory to `PYTHONPATH` instead. See [Non-Extra Calculators](../../installation.md#non-extra-calculators) for details.

    ```bash
    git clone --depth 1 https://github.com/IBM/materials.git
    export PYTHONPATH="$PWD/materials/models/pos_egnn:$PYTHONPATH"
    ```
